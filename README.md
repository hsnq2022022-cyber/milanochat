# milanochat
تطبيق إدارة ســوشـــيــــال على غرار موقعgetawn

## Flow Builder المرئي (تطوير)

الموقع: `#/flows` من لوحة التحكم. المحرر الجديد يستخدم `@xyflow/react@12.12.0` وZustand مع الحفاظ على هوية إدارة سوشيال.

### الاستخدام والاختبار
- `npm ci` ثم `npm run dev` لتشغيل الموقع محلياً.
- `npx tsc --noEmit -p tsconfig.flows.json` للتحقق الصارم من ملفات المحرر.
- `npm run test:flows` لاختبار منطق إنشاء الروابط والتحقق والترحيل من المسودات القديمة.
- `npx playwright install chromium` ثم `npm run test:browser` لاختبار التحرير في المتصفح.
- `npm run build` للتحقق من بناء الموقع.

### تعديل التدفق
يمكن سحب العقد وربط مقابضها، ثم النقر على الخط أو سحب طرفه لتغييره، والحذف بزر Delete أو من زر الحذف. اضغط بزر الفأرة الأيمن على الخط للحصول على قائمة الإدراج والحذف. يدعم المحرر التراجع والإعادة، ونسخ العقد ولصقها، وخريطة مصغرة، وتوزيع عشوائي وتجربة محلية. الحفظ تلقائي داخل هذا المتصفح ويمكن تصدير المسودة واستيرادها. يحاول النظام ترحيل المسودة السابقة `social_flow_visual_v2` مع الإبقاء على بياناتها.

### حدود النسخة الحالية
- التدفقات **مسودات محلية** وليست أتمتة مفعّلة على حسابات Instagram أو Facebook أو WhatsApp.
- لا يجري رفع الصور إلى Supabase، أو تنفيذ HTTP خارجي من المتصفح، أو تسجيل أحداث Meta، أو خصم أرصدة.
- تفعيل الرسائل والتأخيرات والإجراءات الحقيقية يحتاج مسارات مصادقة وتخزين آمنة، وتكامل Meta مع سياسات نافذة المراسلة واختبارات مستقلة.
- لا تغيّر `milan-api` أو إعدادات المصادقة أو المدفوعات لاستعمال هذا المحرر.
