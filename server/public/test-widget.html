🧪 صفحة اختبار Widget Milano

هذه صفحة اختبار على نطاق خارجي للتحقق من عمل widget الشات.

ملاحظة: يجب استبدال YOUR_DOMAIN و WIDGET_TOKEN بالقيم الصحيحة.

كود التضمين:

<script 
    src="https://YOUR_DOMAIN/widget.js" 
    data-token="WIDGET_TOKEN">
</script>

قائمة التحقق:

  • يظهر زر widget في زاوية الصفحة
  • عند النقر يفتح نافذة المحادثة
  • تظهر رسالة الترحيب والأسئلة المقترحة
  • يمكن إرسال رسالة جديدة
  • يظهر مؤشر "يكتب الآن" بعد الإرسال
  • يتم بث الرد حرفاً بحرف (Streaming)
  • لا توجد أخطاء CORS في Console المتصفح
  • المحادثة تُحفظ في قاعدة البيانات
  • التصميم متجاوب على الجوال
  • الاتجاه RTL صحيح للعربية

خطوات الاختبار:

  1. افتح لوحة تحكم Milano وأنشئ widget جديد
  2. انسخ الـ Token الخاص بالwidget
  3. عدّل هذه الصفحة واستبدل YOUR_DOMAIN و WIDGET_TOKEN
  4. افتح الصفحة في المتصفح
  5. افتح Console المتصفح (F12) للتحقق من عدم وجود أخطاء
  6. أرسل رسالة واختبر الرد
✅ الميزات المطبقة:
  • Shadow DOM لعزل التنسيقات
  • CORS مع التحقق من النطاقات
  • Visitor ID فريد يُحفظ في localStorage
  • بث مباشر للردود (Streaming)
  • مؤشر "يكتب الآن"
  • معالجة الأخطاء وعرضها للمستخدم
  • دعم كامل للعربية وRTL
  • إمكانية الوصول (Keyboard, ARIA)
  • حفظ المحادثة أثناء التنقل
