## الدفع — حالة التشغيل

- الحساب التاجر غير مربوط بحسب تصريح صاحب المشروع.
- مصدر `topup-create` موجود في main لكن لم يكن منشورًا في قائمة Edge Functions؛ الواجهة كانت تستدعيه وتظهر نجاحًا خاطئًا حتى عند غياب رابط دفع.
- تم تجهيز `PAYMENTS_ENABLED` + `WAYL_TOPUP_WEBHOOK_ENABLED` و`VITE_WAYL_CHECKOUT_ENABLED` وكلها OFF.
- تمت إضافة `supabase/functions/wayl-topup-webhook` الجديدة دون المساس بدالة `wayl-webhook` التاريخية.
- ترحيل `20261028230000_wayl_atomic_topup.sql` في المستودع **غير مطبق**؛ يلزم قرار SQL مستقل.
- يجب تشغيل Wayl **test** قبل **live**، استخدام `WAYL_TOKEN` و`WAYL_WEBHOOK_SECRET` عبر Supabase Secrets فقط، `SITE_URL` موثوق HTTPS، وربط webhook عبر الدالة الجديدة ببوابة `verify_jwt=false` لأنها موقّعة HMAC من Wayl.
- لا يمكن ضمان منح الرصيد صحيحًا إلا بعد اختبارات تحويل Wayl حقيقية؛ إسقاط الرسائل أو التوقيعات المزوّرة يجب أن يكون مستحيلًا، وفشل الطلب بعد إنشاء رابط مجهول الحالة يتطلب مراجعة بشرية.
- الباقات server-side فقط: 35,000 د.ع / 1,000 رد، 85,000 د.ع / 3,000، 225,000 د.ع / 10,000. لا تستقبل الأسعار أو عدد الردود من الواجهة.
- القرار السابق: **الإجابات التاريخية الخمس للـWidget مجانية**، ولا خصم أو تسوية.
